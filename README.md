# homelab-infrastructure-case-studies

This repo is where I document different case studies based on my Raspberry Pi homelab.

My main homelab repo is where I keep track of the actual technical setup, services, devices, configs, and changes. This repo is different. This repo is more focused on explaining how my homelab can be used to represent real-world IT situations.

The goal is to show what I built, why I built it, how it works, and what I learned from it.

# Purpose

I created this repo to organize case studies from my homelab. Instead of only showing that I installed different services, I want to explain how those services could be used in a real small business or IT environment.

This repo will help me document things like:

how services are hosted
how traffic is routed
how DNS and HTTPS are used
how monitoring is set up
how security alerts are reviewed
how backups and recovery could work
how different infrastructure pieces connect together
what I learned while building and troubleshooting the lab
